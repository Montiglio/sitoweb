# Proloco Montiglio Website

Sito web ufficiale per il dominio `www.prolocomontiglio.it`, progettato per una nonprofit locale.

## Pagine incluse

- `index.html` - pagina principale con introduzione e navigazione
- `about.html` - informazioni sull'organizzazione, missione, storia e obiettivi
- `organization.html` - dettagli legali, ID nonprofit e prova dello status
- `contact.html` - contatti ufficiali e dominio associato
- `styles.css` - stili per la grafica
- `script.js` - interazione form di contatto

## Come usare

1. Apri `index.html` nel browser
2. Inserisci i dati reali nelle pagine `about.html`, `organization.html` e `contact.html`
3. Pubblica i file su un hosting statico
4. Configura il record DNS del tuo dominio `www.prolocomontiglio.it` verso l'hosting

## Nota

Questo sito è pensato per un'organizzazione nonprofit. Aggiungi tutti i dati richiesti: ID nonprofit, indirizzo fisico, informazioni di registrazione, budget e rendicontazione, e-mail ufficiale associata al dominio e dettagli organizzativi aggiornati.
